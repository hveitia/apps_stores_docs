2. Descripción del Servicio

Xari Crud es un cliente móvil CRUD dinámico que se conecta a backends XAF Web API. La aplicación descubre entidades OData mediante Swagger/OpenAPI y genera automáticamente pantallas de listado, detalle y edición para la gestión de datos.

Importante: Xari Crud es una herramienta cliente que depende de un servidor XAF Web API externo. La aplicación no proporciona ni aloja servicios de backend propios.
