Política de Privacidad

Xari Crud

Última actualización: Marzo 2026

1. Introducción

La privacidad de nuestros usuarios es fundamental. Esta Política de Privacidad explica qué información recopilamos, cómo la usamos y qué derechos tienes sobre tus datos personales al usar Xari Crud, un cliente móvil CRUD dinámico que se conecta a backends XAF Web API.

2. Información que Recopilamos

Información proporcionada por el usuario

  • URL del servidor: La dirección del servidor XAF Web API que configuras para conectarte. Se almacena de forma segura en el dispositivo mediante almacenamiento seguro (Secure Storage).
  • Credenciales de autenticación: Nombre de usuario y contraseña que proporcionas para autenticarte en el servidor XAF. Estas credenciales se envían al backend para obtener un token JWT y no se almacenan permanentemente en el dispositivo.
  • Token de autenticación (JWT): El token obtenido del servidor se almacena en el almacenamiento seguro del dispositivo para mantener la sesión activa.

Información generada por el uso

  • Preferencias de la aplicación: Configuraciones como el tema visual y la visibilidad de entidades. Se almacenan localmente en el dispositivo.

Información que NO recopilamos

  • Ubicación del dispositivo.
  • Fotos, archivos multimedia o contactos.
  • Identificadores del dispositivo.
  • Datos de uso, analíticas o métricas.

3. Almacenamiento de Datos

Almacenamiento Local

  • La URL del servidor y el token JWT se almacenan en el almacenamiento seguro del dispositivo (Secure Storage), protegido por las medidas de seguridad del sistema operativo.
  • Las preferencias de la aplicación (tema, visibilidad de entidades) se almacenan localmente en el dispositivo.
  • Xari Crud no mantiene una base de datos local de los registros del servidor. Los datos se consultan en tiempo real desde el backend XAF.

Almacenamiento en la Nube

  • Xari Crud no utiliza servicios en la nube propios.
  • Toda la comunicación de datos ocurre exclusivamente entre la aplicación y el servidor XAF Web API configurado por el usuario.
  • El almacenamiento y procesamiento de los datos de negocio es responsabilidad del servidor XAF y su administrador.

4. Comunicación con Terceros

Xari Crud no envía datos a servicios de terceros. Específicamente:

  • No utiliza Firebase ni ningún servicio de Google Cloud.
  • No incluye SDKs de analíticas ni reportes de errores.
  • No contiene publicidad ni SDKs publicitarios.
  • Los controles de UI de DevExpress MAUI se ejecutan exclusivamente en el lado del cliente y no transmiten datos a DevExpress.

La única comunicación externa es con el servidor XAF Web API que tú configuras, y se realiza exclusivamente mediante conexiones HTTPS cifradas.

5. Seguridad de los Datos

Implementamos las siguientes medidas de seguridad:

  • Cifrado en tránsito mediante HTTPS/TLS para toda comunicación con el servidor XAF.
  • Almacenamiento seguro del dispositivo (Secure Storage) para credenciales y tokens.
  • Las contraseñas no se almacenan permanentemente; solo el token JWT se conserva en el dispositivo.
  • El token JWT tiene una vigencia limitada definida por el servidor XAF.

Importante: La seguridad de los datos de negocio depende de la configuración del servidor XAF al que te conectes. Asegúrate de conectarte únicamente a servidores de confianza con certificados SSL válidos.

6. Retención de Datos

  • Token JWT: Se conserva hasta que cierres sesión, expire el token o desinstales la aplicación.
  • URL del servidor: Se conserva hasta que la cambies o desinstales la aplicación.
  • Preferencias: Se conservan hasta que las modifiques o desinstales la aplicación.

7. Eliminación de Datos

Puedes eliminar tus datos en cualquier momento:

  • Cerrar sesión elimina el token JWT del almacenamiento seguro.
  • Desinstalar la aplicación elimina todos los datos locales (URL del servidor, token, preferencias).

Nota: Los datos almacenados en el servidor XAF son gestionados por el administrador del servidor y están fuera del alcance de esta aplicación.

8. Privacidad de Menores

Xari Crud no está dirigida a menores de 13 años. No recopilamos intencionalmente información personal de menores de 13 años. Si descubrimos que hemos recopilado datos de un menor de 13 años, eliminaremos esa información inmediatamente.

9. Tus Derechos

Según las leyes de protección de datos aplicables (GDPR, CCPA, etc.), tienes derecho a:

  • Solicitar información sobre qué datos almacena la aplicación.
  • Eliminación de tus datos locales (mediante cierre de sesión o desinstalación).
  • Oposición al procesamiento para ciertos fines.

Dado que Xari Crud almacena datos exclusivamente en tu dispositivo y no en servidores propios, tienes control total sobre tus datos en todo momento.

Para ejercer estos derechos o realizar consultas, contacta con nosotros en hveitia86@gmail.com

10. Transferencias Internacionales de Datos

Xari Crud no transfiere datos a servidores propios. La comunicación ocurre únicamente con el servidor XAF configurado por el usuario. La ubicación y jurisdicción de dicho servidor es responsabilidad del usuario y del administrador del servidor.

11. Cookies y Tecnologías de Seguimiento

Xari Crud no utiliza cookies, tecnologías de seguimiento, identificadores de dispositivo ni herramientas de analítica de ningún tipo.

12. Cambios a esta Política de Privacidad

Podemos actualizar esta Política de Privacidad ocasionalmente. Te notificaremos de cambios significativos mediante:

  • Una notificación en la aplicación.
  • Actualizando la fecha de "Última actualización" en este documento.

El uso continuado de la aplicación después de los cambios constituye tu aceptación de la nueva política.
